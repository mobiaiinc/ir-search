# 화이트스페이스 조사 C — 주식·코인·블록체인 (한일 크로스보더 신사업 후보)

- 조사일: 2026-09-20
- 대상 회사: 한국 외국인관광 도시민박 운영사 → 도쿄 외국인·비즈니스 여행자 대상 먼슬리 가구부 주택 플랫폼(AI 심사 + 家賃債務保証, 宅建業, 일본 법인·経営管理 비자, 개발자 1명)
- 조사 범위: 주식(증권·투자정보) / 코인(가상자산) / 블록체인(RWA·스테이블코인·토큰화) 영역에서 (a) 거의 아무도 하지 않고 (b) 성장 근거가 있고 (c) 당사 자산(주거·임대료 현금흐름, 외국인 데이터, 일본 법인, AI·개발)으로 선점 가능한 것
- 방법: 웹검색 160회(본 조사 51회 + 보조조사 A 55회 + 보조조사 B 54회, 한·일·영). 원문 페이지 다수 접근 불가 → 검색 스니펫 기준. 모든 수치 뒤에 [출처] 병기, 확인 불가는 **미확인**. 일본어 스니펫의 "billion yen"은 대부분 "億円" 오역으로 판단되어 億円으로 표기했고, 원문 재확인을 권장.
- 참고: 지시문의 컨텍스트 문서(japan-monthly-c2c-strategy-2026-09.md)는 저장소에 없어, 같은 계열 문서인 docs/foreigner-monthly-strategy-2026-09.md(0·6·7·8절)를 컨텍스트로 사용했다.
- 판정 규칙: 직접 경쟁 플레이어 3곳 이상 확인 → "이미 존재". 0~2곳 → 공백(화이트스페이스) 후보.

## 0. 결론 요약

1. **"토큰·코인 그 자체"로는 공백이 거의 없다.** 엔 스테이블코인 발행(JPYC·SBI JPYSC·3메가뱅크·DCJPY), 한일 법정화폐 송금(7개사+), 일본 크립토 결제 게이트웨이(Slash·Nudge·Binance Japan 등), 포인트→토큰(4건), 일본 부동산 ST(호텔·레지던스 3건+)는 모두 "이미 존재"다. 한국 부동산 조각투자 1세대는 2026년에 붕괴했다(카사 종료 2026-08-10, 펀블 파산 2026-07-03).
2. **공백은 "외국인 임차인의 돈이 움직이는 접점"에 있다.** (a) 재류 6개월 미만 외국인이 일본 은행계좌 없이 월세·보증금·초기비용을 스테이블코인으로 내는 서비스는 0건, (b) 월세 납부 이력을 국경을 넘어 신용으로 바꿔주는 서비스는 일본·한국 모두 0건(반대 방향인 "모국 신용→일본 입주심사"만 Dwilar 1곳), (c) 외국인 전용 먼슬리 주택 수익을 소액 투자자에게 파는 디지털증권은 0건, (d) 家賃債務保証 채권의 토큰화는 0건.
3. **추천 순위(스코어링 표 4절)**: ① 재류 초기 외국인용 스테이블코인 월세·보증금 결제 지갑(22/25) ② 월세 이력 기반 한일 "신용 여권"(21) ③ AI 家賃保証 심사 + 보증채권 토큰화(18) ④ 외국인 먼슬리 주택 수익 디지털증권(17) ⑤ 재류 외국인 자산관리·귀국 정산(17).
4. **라이선스가 승부를 가른다.** 가맹점(당사)이 JPYC·USDC를 "직접 수취"만 하면 일본에서 등록이 불필요하지만, 엔화로 환전해 주는 순간 暗号資産交換業 또는 電子決済手段等取引業(자본금 1,000만엔, 실무 1년 이상, 수천만엔 이상)이 필요하다. 개인 한일 송금은 일본 資金移動業 + 한국 소액해외송금업(자기자본 10억원)이 필요해 당사가 직접 하기엔 무겁다 → 라이선스 보유사(Coinshot·한패스·SBI VC) 제휴가 전제.
5. **한국 쪽 시계**: 토큰증권법은 2026-01-15 통과·2027-01 시행, 디지털자산기본법(원화 스테이블코인)은 2026-09-20 현재 미통과. 일본 쪽: 暗号資産 金商法 이관 개정안 2026-07-15 성립(기사 기준), 분리과세 20.315%는 2028-01-01 적용 전망.
