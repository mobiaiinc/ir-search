# 0005 — `--drop-expired`는 파싱되는 과거 날짜만 버린다

## 맥락
기업마당은 모집중 목록에 마감 지난 공고가 섞여 나와 SKILL.md가 "마감일 필터를 반드시 적용"하라고 했지만 모델이 손으로 걸렀다. 크롤러 옵션으로 만들면서 "마감을 못 읽는 항목"의 처분을 정해야 했다.

## 결정
오늘보다 이전 날짜로 **파싱되는** 항목만 버린다. 빈 값, "상시", "예산 소진 시까지", 파싱 실패는 남긴다.

## 대안
- 못 읽는 것도 버리기: 상시 모집 사업(창업 인프라·법률 상담 등)이 통째로 사라진다. 이 스킬의 존재 이유가 "놓치지 않기"라 반대 방향의 오류
- 못 읽는 것을 별도 파일로: 파일이 늘고 모델이 두 파일을 읽어야 한다. 남겨 두고 검토 때 판단하는 편이 단순

## 결과
- 마감 파싱이 깨지면(사이트 개편) 필터가 아무것도 안 버리고 조용히 통과한다 — "마감 전부 빈 값"은 파서 의심 신호 (engineering-notes)
- 보고서에서 "상시" 항목은 모델이 마감 대신 "상시"로 적는다
