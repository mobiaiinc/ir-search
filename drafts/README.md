# drafts/ — 같은 패턴의 자매 스킬 설계 초안

ir-search가 굳힌 패턴을 다른 대상에 옮기는 초안이다. **코드는 없고 설계와 SKILL.md 초안만 있다.** 확정되면 각각 자기 저장소로 나가고 이 폴더는 비운다 (아래 "공통 킷" 결정과 함께).

| 초안 | 대상 | 산출물 | 상태 |
|---|---|---|---|
| [stock-search](stock-search/DESIGN.md) | 한국·미국·일본 상장기업 공시(1차 자료) 전수 수집 → 관심 프로필 기준 판정 | 사건 보고서 + 기한 큐 | 설계 초안. 소스 URL·API 미검증 |
| [jp-grants](jp-grants/DESIGN.md) | 일본 정부·자치체 공모·보조금·AI 지원사업 전수조사 → 판정 → **応募 서류 초안까지** | 보고서 + 応募 패키지 초안 + 기한 큐 | 설계 초안. 소스 URL·API 미검증 |

## 세 스킬이 공유하는 뼈대 (ir-search에서 검증된 것)

```
0 프로필 (한 번만 묻고 파일에 저장)
1 전수 수집 (키워드 검색 금지 · 소스별 크롤러 · 차단은 보고)
2 전수 검토 → 후보 (모델이 목록 전체를 읽음)
3 원문 검증 (1차 자료에서 근거 인용 · 없으면 '불명')
4 판정 A/B/C + 보고서 (모든 항목에 원문 URL)
마무리: 검수 서브에이전트 → 큐(기한) → run finish → status
상태: <project>/.<skill>/{profile.md, worklog.md, queue.jsonl, decisions.md, runs/<날짜>/}
```

무엇이 바뀌고 무엇이 그대로인가:

| 층 | 그대로 | 대상마다 바뀜 |
|---|---|---|
| 도구 | `fetchlib.py`(지문 사다리·차단 판정·지연), `diff_surveys.py`(`(source,id)` 키 비교), `survey_state.py`(워크스페이스) | 소스별 파서(`page_*`), 레코드 스키마의 `id`·기한 필드명, 워크스페이스 폴더명, 큐 종류 |
| 지시 | 0~4단계 골격, '불명' 규칙, 근거 인용 필수, 서브에이전트는 추출·검수만 | 프로필 축, A/B/C의 정의, 보고서 섹션, 함정 목록 |
| 하네스 | `CLAUDE.md`/`AGENTS.md` + `docs/` 슬롯 + `tracking/` | 내용 전부 |

## 공통 킷으로 뺄지 (미결)

세 스킬이 `fetchlib.py`·`diff_surveys.py`·`survey_state.py`를 복사해 쓰면 버그 수정이 세 번이 된다. 선택지:

1. **복사** — 스킬마다 독립. 설치가 단순(clone 하나). 수정이 세 배. ir-search v3가 이 상태
2. **`survey-kit` 저장소 + git subtree/submodule** — 한 곳 수정. 설치 시 서브모듈 초기화가 필요해 "clone 하나"가 깨진다
3. **모노레포 + 플러그인 3개** — `.claude-plugin/marketplace.json`에 플러그인 셋, 스킬은 각자 폴더. 결정 0001(루트 SKILL.md)을 뒤집어야 한다

초안 단계에서는 1(복사)로 시작하고, 두 번째 스킬이 실제로 돌아가는 시점에 2·3을 다시 본다. `survey_state.py`는 워크스페이스 폴더명(`.ir-search`)이 상수라 옮기려면 `--workspace-name` 인자가 먼저 필요하다.

## 초안이 답하지 않은 것 (사용자 확인 필요)

- **stock-search의 A/B/C 정의** — 지원사업의 "즉시 가능/로드맵/변형"을 공시에 옮기면 "즉시 검토(기한 있음)/트리거 대기/관점 전환"이 되는데, 이것이 원하는 용도(공시 모니터링)인지, 아니면 종목 발굴(스크리닝)인지에 따라 소스 구성이 달라진다
- **jp-grants의 応募 범위** — 서류 초안 작성까지인지, jGrants 전자신청 화면 입력 보조까지인지. 어느 쪽이든 **제출은 사람이 한다** (gBizID 로그인 우회 금지)
- **jp-grants 신청 주체** — 일본 법인이 있는지, 한국 법인으로 일본 사업소 없이 응모하는지. 대부분의 補助金이 国内法人·国内事業所 요건이라 이것이 B그룹 트리거의 핵심 축이다
